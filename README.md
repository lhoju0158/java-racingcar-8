# java-racingcar-precourse

### 기능 구현

1. 입력
    1. 경주할 자동차를 입력받는다.
        - 사용자 입력은 다음 규칙을 따른다 가정한다.
            - 쉼표를 기준으로 경주할 자동차를 입력 받는다.
            - 공백을 자동차 이름으로 지정할 수 없다. 입력 시 이를 무시한다.
            - 자동차 이름은 중복이 가능하다. 단, 이 경우 입력 순서에 따라서 구분한다.
        - 다음 규칙을 따르지 않으면 에러처리한다.
            - 자동차 이름 글자 수는 5 이하의 양수이다
            - 자동차의 갯수는 100 이하의 양수이다.
    2. 시도할 횟수를 입력받는다.
        - 다음 규칙을 따르지 않으면 에러처리한다.
            - 횟수는 정수값이다.
            - 횟수는 100 이하의 양수이다.
2. 자동차 경주
    1. 각 자동차는 0부터 9까지 무작위 정수 값을 하나 고른다.
        - `camp.nextstep.edu.missionutils.Randoms`을 이용한다.
    2. 해당 값이 4 이상일 경우 전진한다.
    3. 3 이하일 경우 전진하지 않는다.
3. 출력
    1. 모든 게임이 끝난 후 결과를 출력한다.
        - 각 게임의 결과 또한 개별로 출력하지 않고 끝난 이후 출력한다.
    2. 실행 결과와 우승자를 출력한다.
        - 단독 우승, 공동 우승 모두 가능하다.
