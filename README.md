# java-racingcar-precourse
### 기능 구현
1. 입력
   1. 경주할 자동차를 입력받는다.
      - 다음 규칙을 따르지 않으면 에러처리한다.
        - 쉼표를 기준으로 입력 받는다.
        - 이름은 5자 이하이다
        - 최소 1개 이상의 이름을 입력 받아야 한다.
   2. 시도할 횟수를 입력받는다.
      - 다음 규칙을 따르지 않으면 에러처리한다.
        - 횟수는 양수이어야 한다. (0, 음수는 기대하지 않는다.)
        - 횟수는 integer의 범위를 벗어나지 않는다. 
2. 자동차 경주 
   1. 각 자동차는 0부터 9까지 무작위 값을 하나 고른다.
      - `camp.nextstep.edu.missionutils.Randoms`을 이용한다.
   2. 해당 값이 4 이상일 경우 전진한다.
   3. 3 이하일 경우 전진하지 않는다.
3. 출력
   1. 차수 별 실행 결과를 출력한다.
      - 게임이 끝날 때 마다 결과를 출력한다.
   2. 모든 게임이 끝난 후 우승자를 안내한다.
